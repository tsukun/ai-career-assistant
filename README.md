# AI職務経歴書アシスタント

## 概要

職務経歴を入力すると、生成AIを利用して以下の内容を分析するWebアプリケーションです。

- 職務経歴の要約
- 技術的な強み
- 面接でアピールすべきポイント
- 今後伸ばすべきスキル

個人開発を通して、Java / Spring BootによるWebアプリケーションへ生成AIを組み込む方法を学習することを目的として開発しています。

## 技術構成

- Java 17
- Spring Boot
- Spring AI
- Ollama
- Qwen3.5 9B
- Maven
- Thymeleaf
- HTML / JavaScript
- Git / GitHub

## システム構成

```text
ブラウザ
   ↓ HTTP
Spring Boot
   ↓
Controller
   ↓
Service
   ↓
Spring AI
   ↓
Ollama
   ↓
Qwen3.5 9B
   ↓
AI分析結果
   ↓
ブラウザ
```

## 主な機能

### 職務経歴分析

入力した職務経歴を生成AIへ渡し、以下の内容を生成します。

- 職務経歴の要約
- 技術的な強み
- 面接でアピールすべきポイント
- 今後伸ばすべきスキル

### 事実抽出

職務経歴から記載されている事実を抽出し、その事実をもとにAI分析を行う構成を実装しています。

### 入力バリデーション

- 職務経歴の未入力チェック
- 10,000文字以内の入力制限

### AIエラーへの対応

Spring AIのリトライ設定を利用し、LLMが利用できない場合などのエラーに対応しています。

## 開発目的

生成AIの実務経験を身につけることを目的として、LLMを組み込んだWebアプリケーションを個人開発しています。

既存のJava / Spring BootによるWeb開発経験を活かしながら、Spring AI、LLM、プロンプト設計などの生成AI関連技術を学習しています。

## 実行環境

本アプリケーションでは、ローカル環境でOllamaを実行し、Qwen3.5 9Bを利用しています。

Ollamaを起動した状態でSpring Bootアプリケーションを起動してください。
